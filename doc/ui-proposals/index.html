Ride layout proposals

Three ways to give the workout part of the screen and the rest to integrations (music, podcasts, quiz, coach, calendar). Mock data, simulated ride. Each mock is drawn at the device's real CSS-pixel size and scaled to fit, so the legibility numbers under each one are accurate. These layouts can also be picked in the app: Settings › Options › Layout, or the layout button in the top bar.
